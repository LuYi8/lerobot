## 0. 环境与基线事实

- 任务：`PandaPickCubeKeyboard-v0`（抓方块），fps=10，HIL（人类遥操作干预），wandb project=`hil_test`
- 观测：`observation.state` 18 维 = qpos(7)+qvel(7)+gripper(1)+tcp_pos(3)，**不含方块位置**（真部分可观测，方块位姿只在 front/wrist 图像）；action 4 维 = 3 连续（笛卡尔位移，tanh squash）+ 1 夹爪
- 数据管线：`online_ratio=0.5`（每批 50/50）；离线 buffer = 演示数据集（~582 帧）+ **仅干预** transition（100% 人类动作）
- **基线（2026-08-14 实测，commit 6c9b7e9，eval_simple 评估 n_episodes=100，在线8000/离线2000 配置）**：

| 算法 | 10000 训练步 | 14000 训练步 |
|---|---|---|
| 纯 SAC（无 GRU） | 30% | 45% |
| R-SAC（仅 actor GRU，hidden 256，seq 8） | 55% | **99%** |

- **⚠ 基线可比较性**：决策 7（2026-08-14 确认，当日修订为 **离线8500 / 在线4000**——原 6000 装不下扩采后的 8252 帧演示，`from_lerobot_dataset` 容量不足直接 ValueError）起，消融实验统一用 **离线8500 / 在线4000** 数据管线；99% 历史基线（2000/8000）**仅作参考，不可直接比**，须同配置重跑纯 SAC / R-SAC 基线。
- **无 HIL 消融（2026-08-14，EXP-006/007，τ=0.005，离线=纯演示 150 集 8252 帧、全程无干预，在线=自身探索 1500；运行目录 `SACoutput150t=0.005` / `GRUoutput150t=0.005`）**：

| 算法 | 5000 训练步 |
|---|---|
| 纯 SAC（无 GRU） | 88% |
| R-SAC（仅 actor GRU，hidden 256，seq 8） | **100%** |

  扩演示量 + τ=0.005 后**无 HIL 纯 RL 也可学**（vs 历史 HIL 纯 SAC 14000 步 45%），GRU 增益仍在（88→100）。

## 3. 消融实验记录

> 每次消融：目的 / 配置（完整 CLI 见 方案2 文档 §5）/ 结果 / 结论。

- **EXP-004（仅 critic GRU）**：隔离 critic 循环的贡献（actor 保持前馈）。配置：`--algorithm.sequence_length 8 --algorithm.critic_use_recurrent true --algorithm.use_torch_compile false --policy.offline_buffer_capacity 8500 --policy.online_buffer_capacity 4000`。**待跑**。
- **EXP-005（双关）**：完整方案，目标实验。配置：EXP-004 基础上加 `--policy.policy_kwargs.use_recurrent true --policy.policy_kwargs.recurrent_hidden_size 256 --policy.policy_kwargs.recurrent_num_layers 1`。**待跑**。
- 对照：EXP-002 / EXP-003（同 8500/4000 配置、同 `use_torch_compile false` 的纯 SAC / R-SAC 基线重跑）。
- **EXP-006 / EXP-007（无 HIL 消融，2026-08-14，已完成）**：目的——去掉人类在回路（actor 只自动 rollout 不干预，离线 buffer=纯演示），检验 150 集 8252 帧演示 + τ=0.005 下纯 RL 的可学性。配置：train json τ=0.005（actor json 已同步）、离线8500/在线1500、`online_ratio=0.5`、batch 64、compile true（json 默认）；R-SAC 侧加 `use_recurrent true / hidden 256 / layers 1 / sequence_length 8`（完整命令见 `命令.txt`"无 HIL 消融实验"小节）。结果：5000 优化步（checkpoint 005000）纯 SAC **88%**、R-SAC **100%**。结论：① 扩演示 + τ=0.005 后无 HIL 也能学（vs 历史 HIL 纯 SAC 14000 步 45%）；② GRU 增益仍在（88→100），且比历史 HIL R-SAC（14000 步 99%）更早饱和。
